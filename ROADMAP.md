# Roadmap

What is planned next:

- **GitHub Action** - run the checklist on pull requests and fail the check
  below a configurable score
- **Suggested topics** - propose relevant topics from the repository's language,
  description and README instead of only counting them
- **Fix hints per check** - inline remediation steps in the report
- **Badge output** - a shields.io endpoint for your readiness score
- **Config file** - `.launchchecklist.yml` for custom thresholds

Ideas and corrections are welcome - open an issue or message us on Telegram.
