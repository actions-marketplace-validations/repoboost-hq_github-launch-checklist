# The ten checks - why they matter and how to fix them

## 1. Repository name

The name is the strongest text-match signal in GitHub search. A repo called
`my-tool` is invisible; `cloudflare-turnstile-solver` matches exactly what
people type. **Fix:** rename the repository to the phrase people search for
(Settings > rename). Old URLs redirect automatically.

## 2. Description

The About line appears in search results, social cards and your profile. Empty
descriptions are the most common reason a repo does not surface.
**Fix:** one line, 20-300 characters, front-load the keywords.

## 3. Topics

Topics are GitHub's search filters. Under five topics, you are absent from most
filtered searches. **Fix:** add 5-10 relevant topics (repo page > About >
Topics).

## 4. README

The README is what search engines and visitors actually read. **Fix:** answer
what it does, who it is for and how to start - in that order - and keep it
above 300 words with real content.

## 5. License

Without a license, nobody can legally use the code. **Fix:** add a LICENSE
file; MIT is the common default.

## 6. Demo

A homepage or demo link adds a second context for visitors and search engines.
**Fix:** put a docs, demo or landing link in the About section.

## 7. Installation

A repository that does not explain how to install cannot be adopted.
**Fix:** add a quick start block with a copy-pasteable command.

## 8. Contributing guide

A CONTRIBUTING.md tells contributors how to set up and submit changes - and it
signals that the project is maintained. **Fix:** add setup, test and PR
instructions.

## 9. Issue templates

Templates make reports useful and show care. **Fix:** add bug report and
feature request templates under `.github/ISSUE_TEMPLATE`.

## 10. Social preview

The social preview image is what appears when the repository is shared on
social platforms and in some search surfaces. GitHub's API does not expose it,
so this check is manual. **Fix:** Settings > Social preview > upload a 1280x640
image.

## FAQ

### Why is my repo not showing in GitHub search?

Almost always one of three things: an empty description, missing topics, or a
name that does not match any query. Fix those first - they are free and instant.
